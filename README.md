## The line

## How it works

`main.py` (Python 3.13, standard library only, deterministic, no network)
writes that single line — 150 characters, one line of text — to
`$MAKEFUN_OUTPUT_DIR/entry.txt`.

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```
